Версия v1.7

LOUNA GOTHIC PUNK CHROME — v1.5

Состав архива
-------------
1. newtab-extension — кастомная страница новой вкладки.
2. chrome-theme — фиксированная системная тема Chrome «Neon Ruin».

Что нового в v1.5
-----------------
• Стиль системных вкладок зафиксирован на Neon Ruin. Переключатель граффити из настроек удалён.
• На панели вместо «Все закладки» теперь показывается «Другие Закладки».
• «Другие Закладки» содержит только содержимое стандартного раздела Chrome «Другие закладки», без повторной папки «Панель закладок».
• Иконка только у «Другие Закладки» получила отдельную тёмно-красную цветовую схему.
• Панель закладок теперь может занимать почти всю ширину окна и раскладывает элементы слева направо, вместо сжатого центрированного блока.
• Выпадающие папки по-прежнему показывают максимум около 8 строк одновременно, затем появляется вертикальная прокрутка.
• В настройках фона появился режим Manual: размер изображения 25–300%, позиция X 0–100%, позиция Y 0–100%.
• Изменения ручного размера/позиции сохраняются автоматически.

Установка / обновление
----------------------
Открой chrome://extensions и включи «Режим разработчика».

New Tab:
• «Загрузить распакованное расширение» → выбрать папку newtab-extension.
• Если обновляешь прежнюю версию из той же постоянной папки, замени её файлы и нажми «Обновить/Reload».

Neon Ruin Theme:
• Удали/отключи предыдущие варианты Louna Theme, если они были загружены.
• «Загрузить распакованное расширение» → выбрать папку chrome-theme.
• В архиве теперь только один вариант системной темы — Neon Ruin.

Ручная настройка фона
---------------------
Открой ⚙ → Фон → «Способ отображения» → Manual.
• Размер фона — масштаб изображения относительно ширины окна.
• Позиция X — перемещение по горизонтали.
• Позиция Y — перемещение по вертикали.
• Кнопка «100% / центр» возвращает ручные параметры к базовому значению.

Разрешения расширения
---------------------
storage — сохранение настроек.
favicon — получение favicon сайтов.
bookmarks — чтение и редактирование закладок Chrome.

Примечание
----------
Системная тема Chrome и страница New Tab — две отдельные части. Neon Ruin применяется через папку chrome-theme, а настройки фона/закладок/ярлыков — через newtab-extension.


=== НОВОЕ В v1.7 ===

1. Neon Ruin усилен: активная вкладка/toolbar используют более заметную grunge-текстуру с красной неоновой линией; неактивные вкладки получили отдельную более тёмную текстуру.
2. Закладки на кастомной верхней панели поддерживают drag-and-drop мышью:
   - менять порядок на панели;
   - менять порядок внутри папок;
   - переносить закладки и папки в другие папки;
   - вытаскивать элементы обратно на панель;
   - переносить элементы в «Другие Закладки» и обратно.
3. Системные корневые папки Chrome («Панель закладок», «Другие закладки») сами по себе не перемещаются — это ограничение Chrome. Их содержимое перемещать можно.

Подсказка: при перетаскивании красная подсветка показывает место вставки. Центр папки означает «переместить внутрь», край элемента — вставить до/после.
